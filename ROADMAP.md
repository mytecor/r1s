# r1s roadmap

The roadmap follows the same three-level structure as the adjacent Lattice repository:

1. **Plan** — [`roadmap/VISION.md`](./roadmap/VISION.md) describes direction, milestones,
   and invariants without implementation detail.
2. **Features** — each feature has a directory under [`roadmap/`](./roadmap/) and is indexed
   by [`roadmap/features/README.md`](./roadmap/features/README.md).
3. **Tasks** — concrete task files live beside their feature and are indexed by
   [`roadmap/tasks/README.md`](./roadmap/tasks/README.md).

Open decisions and consciously deferred work live in
[`roadmap/BACKLOG.md`](./roadmap/BACKLOG.md).

Start with [`roadmap/README.md`](./roadmap/README.md).
