# F4 — Owner workflow

## Outcome

An owner can publish demand, collect offers, select one allocator, inspect state, cancel work, and
retrieve a retained result.

## Completion criteria

- CLI operations map to asynchronous protocol messages.
- Offer selection is deterministic and policy-driven.
- Owner state survives local process restart.
