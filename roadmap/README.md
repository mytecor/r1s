# r1s roadmap

This directory separates direction from implementation detail so the project can be understood at
the right depth.

## Three levels

| Level | Location | Purpose |
| --- | --- | --- |
| Plan | [VISION.md](./VISION.md) | Goal, milestones, and invariants |
| Features | [`features/`](./features/README.md) | Ordered feature registry and completion criteria |
| Tasks | [`tasks/`](./tasks/README.md) | Concrete implementation units and status |

Feature details and their tasks live together in directories such as
[`f1-protocol-foundation/`](./f1-protocol-foundation/README.md).

Use [BACKLOG.md](./BACKLOG.md) for unresolved decisions and intentionally deferred work.
