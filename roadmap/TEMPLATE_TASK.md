# Task template

Copy this file into your feature directory as
`roadmap/<feature-id>-<feature-slug>/<feature-id>-<task-id>-<task-slug>.md` and fill it in.
`<feature-id>` is the feature number, `<feature-slug>` the feature slug, `<task-id>` the task number,
`<task-slug>` the task slug. Example: `roadmap/f1-protocol-foundation/f1-01-control-protocol.md`.

Then link the task from the feature file (`README.md` in the feature directory).
